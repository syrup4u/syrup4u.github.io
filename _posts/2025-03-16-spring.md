## 背景

因为需要在一个现有系统中加入交换信息的功能，综合考虑了请求频率和信息量，决定用 http 而不是 grpc 。而为了避免写过多底层代码来实现 http 的处理逻辑，就打算用现有成熟的 Spring 框架。

## 问题描述

因为是想在一个原型系统中集成 Spring 的功能，而且是作为一个单独的模块集成进去的，这样对原有的系统影响更小，侵入度更低。

而在 http server 中需要调用原型系统中的一些实例来获取信息，这就意味着和一般的案例不太一样，因为很多实例是在原型系统中实例化与使用的，我们需要做一些调整才能在原型系统中接入 Spring 。

## 前置

虽然有其他语言的基础，但之前没用过 Java ，也完全不熟悉 Spring 的框架，只是听说过这个框架而已。所以需要学习，结合 ChatGPT 和 DeepSeek 可以加速学习的过程，有不懂的也可以随时问 AI 。

而这也有一个很好的[资源](https://liaoxuefeng.com/books/java/spring/index.html)，不仅有 Java 的基础内容，也有介绍 Web 开发和 Spring 开发的内容，结合起来再多尝试跑几遍代码测试，学起来就比较快了。

## 结论

两种方式：

1. 还是走 Spring 自带的框架，容器会自动初始化/实例化各个传入的类。然后在原型系统中相比于调用 `new` 来实例化类，通过 `context.getBean(xxx.class)` 来获取容器内已经完成实例化的类，再走原本后续的流程即可。
2. 保留原型系统中已经使用的实例，并将其传入 Spring 的容器里使用。但由于 Spring 启动的时候，会检查所有依赖的类，要求他们必须有一个 Bean ，以保证具有实例可以调用。比如我们要将一个 service 的模块放到 controller 里调用，以返回用户需要的信息，意味着我们需要在 controller 里有一个变量对应这个 service 。那 Spring 会检查 service 有没有 Bean ，没有的话启动会报错。但如果我们只是直接在 service 上加上对应的 annotation - `@Service` ，那会导致容器里的 controller 使用的是 Spring 初始化的 service 实例，而不是原型系统里的那个，导致 Spring 框架与原型系统的分离。要解决这个问题其实需要绕一点路，首先我们不必在原型代码里加 annotation ，只需要在 Spring 启动时使用的 `@Configuration` 里为 service 配上 `@Bean` 的方法返回即可解决报错的问题。但这时候还是有前面那个问题， Spring 里使用的实例与原型系统里不一样。但我们可以用类似 *方式1* 里的方法，先为 controller 加一个 `setService` 的方法，然后通过 `context.getBean` 找到 controller 的实例，最后调用我们加上的这个 `set` 方法把原型系统里的 service 注入到容器里 controller 模块即可。

解释一下区别：

1. 方式1比较简单，然后是 Spring 负责管理类的生命周期和实例化。但不一定那么通用，有时候并不一定好接入原型系统。主要还是根据需求来，如果还是需要原型系统来管理模块的生命周期，那这种方式就不太合适，但大部分情况下这个方式还是比较推荐的，因为后续集成其他模块也会比较方便。**此时 Spring 更像是主干，其他模块或者原型系统变成了 Spring 的分支。**
2. 方式2比较绕，但因为是注入模块的方式，所以对原型系统的侵入更小，只需要调用几个外部方法即可。另外原型系统负责管理模块的生命周期。**此时原型系统是主干， Spring 作为枝干接入原型系统。**

``` java
package com.example.fetcher.model;

import java.util.ArrayList;
import java.util.List;

public class TraceData {
    private String traceId;
    private String data;
    private List<InnerData> innerData;

    public TraceData() {}

    public TraceData(String traceId, String data) {
        this.traceId = traceId;
        this.data = data;
        this.innerData = new ArrayList<>();
        this.setInnerDatas(2);
    }

    public String getTraceId() {
        return traceId;
    }

    public void setTraceId(String traceId) {
        this.traceId = traceId;
    }

    public String getData() {
        return data;
    }

    public void setData(String data) {
        this.data = data;
    }

    public List<InnerData> getInnerData() {
        return innerData;
    }

    public void setInnerData(InnerData innerData) {
        this.innerData.add(innerData);
    }

    public void setInnerDatas(int i) {
        for (int j = 0; j < i; j++) {
            this.innerData.add(new InnerData("Inner Data " + j));
        }
    }

    public static class InnerData {
        private String innerData;
        public int tempID;
        static int id = 0;

        public InnerData() {}

        public InnerData(String innerData) {
            this.innerData = innerData;
            this.tempID = id;
            id++;
        }

        public String getInnerData() {
            return innerData;
        }

        public void setInnerData(String innerData) {
            this.innerData = innerData;
        }
    }
}
```

`TracingService.java`:

```java
package com.example.fetcher.service;

import com.example.fetcher.model.TraceData;
import org.springframework.stereotype.Service;

import java.util.ArrayList;
import java.util.List;

@Service
public class TracingService {

    private final List<TraceData> traces = new ArrayList<>();

    public TracingService() {
        traces.add(new TraceData("1", "Trace Data 1"));
        traces.add(new TraceData("2", "Trace Data 2"));
    }

    public TraceData getTraceById(String traceId) {
        return traces.stream()
                .filter(trace -> trace.getTraceId().equals(traceId))
                .findFirst()
                .orElse(new TraceData(traceId, "No data found"));
    }

    public void addTrace() {
        traces.add(new TraceData("3", "Trace Data 3"));
    }

    public List<TraceData> getAllTraces() {
        return traces;
    }
}
```

方式1的 `FetcherServer.java`:

```java
package com.example.fetcher;

import java.util.List;

import org.springframework.beans.factory.annotation.Autowired;
// import org.springframework.boot.SpringApplication;
import org.springframework.boot.WebApplicationType;
import org.springframework.context.ConfigurableApplicationContext;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.reactive.function.client.WebClient;
import org.springframework.boot.builder.SpringApplicationBuilder;

import com.example.fetcher.model.TraceData;
import com.example.fetcher.service.TracingService;

import reactor.core.publisher.Flux;

import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class FetcherServer {
    // @Autowired
    // private TracingService tracingService;
    private final SpringApplicationBuilder builder;
    private ConfigurableApplicationContext context;

    // @Autowired
    public FetcherServer() {
        this.builder = new SpringApplicationBuilder()
            .sources(FetcherServer.class)
            .properties("server.port=" + 12345)
            .web(WebApplicationType.SERVLET);
    }

    public void start() {
        context = builder.run();
        // context = SpringApplication.run(FetcherServer.class);
    }

    public void stop() {
        context.close();
    }

    public TracingService getTracingService() {
        return context.getBean(TracingService.class);
    }

    @RestController
    @RequestMapping("/tracing")
    public class TracingController {
        private final TracingService tracingService;

        @Autowired
        public TracingController(TracingService tracingService) {
            this.tracingService = tracingService;
        }

        @GetMapping("/{traceId}")
        public TraceData getTrace(@PathVariable String traceId) {
            return tracingService.getTraceById(traceId);
        }

        @GetMapping("/all")
        public List<TraceData> getAllTraces() {
            return tracingService.getAllTraces();
        }
        @GetMapping("/inner/{traceId}")
        public List<TraceData.InnerData> getInner(@PathVariable String traceId) {
            TraceData traceData = tracingService.getTraceById(traceId);
            return traceData.getInnerData();
        }

        @GetMapping("/inner/all")
        public List<List<TraceData.InnerData>> getAllInner() {
            return makeRequest();
        }
    }

    public List<List<TraceData.InnerData>> makeRequest() {
        System.out.println(Thread.currentThread().getName());
        WebClient wc = WebClient.create("http://localhost:12345");
        Flux<List<TraceData.InnerData>> responses = Flux.fromIterable(List.of("1", "2", "3"))
            .flatMap(traceId -> wc.get()
                .uri("/tracing/inner/" + traceId)
                .retrieve()
                .bodyToFlux(TraceData.InnerData.class)
                .doOnRequest(req -> System.out.println(Thread.currentThread().getName()))
                .doOnNext(res -> System.out.println(Thread.currentThread().getName()))
                .collectList());
        List<List<TraceData.InnerData>> innerData = responses.collectList().block();
        return innerData;
    }
}
```
